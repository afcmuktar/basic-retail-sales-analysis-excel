# Basic Retail Sales Analysis | Excel

One of my first data-analysis projects, completed entirely in Microsoft Excel.

## Project overview
I explored retail transactions to understand sales by product category, month, gender, and age group.

## Tools and methods
- Microsoft Excel
- PivotTables
- Timeline filters
- KPI summaries and dashboard charts

## Key results
- 1,000 transactions and 2,514 units sold
- Total sales value: 456,000
- Electronics had the highest sales value by product category
- May had the highest monthly sales value
